# Data

All data is public research data. **Not for clinical use.** No attempt is made to identify any patient.

| Data | Source | Licence / terms | In this repo |
|---|---|---|---|
| Case records, recorded AJCC stage, node counts | NCI Genomic Data Commons (GDC) API, project TCGA-BRCA, open access | NIH / GDC data access policies for open-access data; cite TCGA | Not stored: read live through Zetaris |
| Pathology report text | TCGA-Reports (Kefeli et al., Tatonetti Lab), github.com/tatonetti-lab/tcga-path-reports | MIT | Not committed (`data/reports/` is git-ignored); 4 reports in `app/web/sample/cases.json` for offline sample mode |
| Original scanned report PDFs | NCI GDC, data type "Pathology Report", open access | GDC open-access terms | Not committed (`data/scans/` is git-ignored); downloaded on demand |
| Staging rules (59) | Paraphrased from public NCI sources: the PDQ cancer treatment summaries (breast "PDQ-B", colon "PDQ-C"), the NCI Thesaurus (NCIt codes) and SEER coding references; each rule carries its citation in the `cite` column; no AJCC text is reproduced | Our paraphrase; the AJCC Cancer Staging Manual is the authoritative text | `data/reference/staging_rules.csv` (generated by `app/usl/rules.py`) |

Citations:
- Kefeli J, Tatonetti N. TCGA-Reports: a machine-readable pathology report resource for benchmarking text-based AI models. Patterns, 2024.
- The Cancer Genome Atlas Network. Comprehensive molecular portraits of human breast tumours. Nature, 2012.
